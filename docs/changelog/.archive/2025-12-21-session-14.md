## Added

### `src/utils/claude-args.ts` - **NEW**
Centralized utilities for Claude CLI operations:

```typescript
// Build CLI arguments for background processes
export function buildClaudeArgs(options: ClaudeArgsOptions): string[]

// Build args for terminal slash commands (no stream-json)
export function buildTerminalArgs(options): string[]

// Build args for interactive sessions (just --resume)
export function buildInteractiveArgs(sessionId?: string): string[]

// Normalize paths to OS-native separators
export function normalizePathForOS(inputPath: string | undefined): string | undefined

// Wrap command in PowerShell on Windows to preserve backslash paths
export function buildTerminalCommand(
  claudeCommand: string,
  cwd: string | undefined,
  wslEnabled: boolean
): { command: string; needsSeparateCd: boolean }
```

## Changed

### `src/extension.ts`
- **6 spawn locations** now use centralized `buildClaudeArgs()`:
  - `_spawnPanelProcess()`
  - `_sendMessageToClaude()`
  - `_prespawnClaudeProcess()`
  - `_executeSlashCommand()`
  - `_openMCPTerminal()`
  - `_openModelTerminal()`

- **Terminal commands** now use `buildTerminalCommand()` which wraps in PowerShell on Windows:
  ```typescript
  // Before: Direct command in Git Bash (converts to forward slashes)
  terminal.sendText(`claude --resume ${sessionId}`);

  // After: Wrapped in PowerShell (preserves backslashes)
  powershell -NoProfile -Command "Set-Location -LiteralPath 'c:\HApps\project'; claude --resume ..."
  ```

- **All cwd paths** now use `normalizePathForOS()` to ensure backslashes on Windows
