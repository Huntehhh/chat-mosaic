## Fixed

### Bug 1.6: Save Race Conditions
- Added 500ms debounce to `_saveCurrentConversation()` to prevent multiple concurrent file writes
- Added force-save in `dispose()` and `_disposePanel()` to ensure data is saved on panel close
- **Fields added**: `_saveDebounceTimer`, `_saveDebounceMs`

### Bug 1.5: Error Message Persistence
- Audited all error message sends - pattern is already consistent:
  - Conversation errors → `_sendAndSaveMessage()` (saved)
  - Operation errors → `_postMessage()` (ephemeral)
