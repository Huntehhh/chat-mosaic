# Changelog - 2025-12-21 (Session 13)

## Independent Concurrent Chats, Token Persistence & MCP Terminal Management

- **Goal**: Enable truly independent concurrent chat panels with per-panel processes and add interactive MCP management
- **Risk Level**: High - Major architectural changes to process management and message routing

Each chat panel now spawns its own Claude process, enabling true concurrent conversations. Token data persists across VS Code restarts. The `/mcp` command opens an interactive terminal for MCP management with automatic process restart.

---

## Quick-Scan Summary

| Metric | Before | After | Change |
|--------|--------|-------|--------|
| Concurrent chat support | Shared process | Per-panel processes | Full independence |
| Token persistence | Lost on restart | Persists | Fixed |
| Message routing | Active panel only | Requesting panel | Correct routing |
| `/mcp` command | Runs `/mcp` command | Interactive session | Full MCP control |

### `extension.ts` - Message Routing & Process Management

**`_postMessage()` priority updated** (lines 801-826):

**`_sendMessageToClaude()` now uses per-panel processes** (lines 1151-1212):

- Spawns new per-panel process if needed
- Falls back to shared ProcessManager for sidebar

**`_spawnPanelProcess()` Windows compatibility** (lines 593-599):

**`_handlePanelProcessMessage()` routing fix** (lines 673-692):

- Routes through full `_processJsonStreamData()` logic

**`_presentLoadedConversation()` session sync** (lines 3516-3523):
- Now updates `panelState.sessionId` when loading conversations

### `extension.ts` - `/mcp` Command (lines 3986-4124)

**Before**: Ran `claude /mcp --resume <id>` in terminal
**After**: Opens interactive `claude --resume <id>` session with terminal close monitoring

```typescript
// Opens interactive session for MCP management
terminal.sendText(`claude --resume ${sessionId}`);

// Listen for terminal close
vscode.window.onDidCloseTerminal(closedTerminal => {
    if (closedTerminal === terminal) {
        this._restartBackgroundProcessForMCP();
    }
});
```
