# Changelog - 2025-12-27 (Session 15)

## Multi-Panel Architecture Fix - Independent Chat Sessions Now Work

- **Goal**: Fix multi-panel Claude chat so each panel has truly independent sessions, conversations, and state
- **Risk Level**: Med - Significant refactoring of shared state to panel-specific state

Resolved critical architectural issues where multiple chat panels shared state (session IDs, conversations, message routing), causing cross-panel contamination. Each panel now operates independently with its own Claude process, session, and conversation history.

## Phase 5: New Session Handler Fix

### Changed: `src/extension.ts` - `_newSession()`

Refactored to properly clear panel-specific state:

```typescript
private async _newSession(panelId?: string): Promise<void> {
  const targetPanelId = panelId || this._requestingPanelId || this._activePanelId;
  const panelState = targetPanelId ? this._panels.get(targetPanelId) : null;

  if (panelState && targetPanelId) {
    // Kill panel's specific process
    const processInfo = this._panelProcesses.get(targetPanelId);
    if (processInfo?.process && !processInfo.process.killed) {
      processInfo.process.kill('SIGTERM');
      this._panelProcesses.delete(targetPanelId);
    }

    // Clear panel-specific state
    panelState.sessionId = undefined;
    panelState.conversation = [];
    panelState.conversationStartTime = undefined;
    panelState.chatName = 'Claude Code Chat';

    // Reset counters
    panelState.totalCost = 0;
    panelState.totalTokensInput = 0;
    panelState.totalTokensOutput = 0;
    panelState.requestCount = 0;

    // Notify only this panel
    panelState.panel.webview.postMessage({ type: 'sessionCleared' });
  }
}
```
