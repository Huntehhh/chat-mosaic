## Changed

### ProcessManager - Close Event Race Condition Fix
**File**: `src/services/ProcessManager.ts`

Changed process identity check in close/error handlers:
```typescript
// Before: Could clear reference to NEW process when OLD process closes
if (!this._currentProcess) { return; }

// After: Only affects the specific process that closed
if (this._currentProcess !== claudeProcess) {
  console.log('Ignoring close event from old process (new process already running)');
  return;
}
```

### ProcessManager - Graceful Shutdown Fix
**File**: `src/services/ProcessManager.ts`

Removed invalid `{ type: 'shutdown' }` message (Claude Code only accepts `'user'` or `'control'`):
```typescript
// Before: Sent invalid message causing stderr error
processToKill.stdin.write(JSON.stringify({ type: 'shutdown' }) + '\n');
processToKill.stdin.end();

// After: Just close stdin (EOF triggers graceful exit)
processToKill.stdin.end();
```

### Extension - Plan Mode Overrides Yolo Mode
**File**: `src/extension.ts` (both `_sendMessageToClaude` and `_prespawnClaudeProcess`)

Plan mode and yolo mode are now mutually exclusive (incompatible flags):
```typescript
if (planMode) {
  args.push('--permission-prompt-tool', 'stdio');
  args.push('--permission-mode', 'plan');
} else if (yoloMode) {
  args.push('--dangerously-skip-permissions');
} else {
  args.push('--permission-prompt-tool', 'stdio');
}
```

### Extension - Settings Persistence
**File**: `src/extension.ts`

Updated `_sendCurrentSettings()` to use frontend-friendly keys and include all display settings:

```typescript
const settings = {

```

### Message Handler Context - Race Condition Fix
**File**: `src/webview/hooks/useVSCodeMessaging.ts`

Split useEffect to prevent listener removal during message arrival:
```typescript
// Before: 30+ dependencies caused listener churn, messages lost during swap
useEffect(() => {
  // setup + listener in same effect with huge dep array
}, [addMessage, updateLastMessage, /* 30+ deps */]);

// After: Stable listener, context updates separately
useEffect(() => { updateHandlerContext(ctx); });  // Updates context
useEffect(() => { /* listener setup */ }, []);     // Stable, never removed
```

## Removed

### CLI `--verbose` Flag
Removed from both `_sendMessageToClaude` and `_prespawnClaudeProcess`. Not required for stream-json mode, recommended off in production.

**Before**: `claude --output-format stream-json --input-format stream-json --verbose ...`
**After**: `claude --output-format stream-json --input-format stream-json ...`
