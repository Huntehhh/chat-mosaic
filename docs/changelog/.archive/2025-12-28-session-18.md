## Track B: StreamProcessor Extraction

### Added: `src/services/StreamProcessor.ts`

New service handling all JSON stream parsing from Claude CLI stdout:

```typescript
export interface StreamProcessorCallbacks {
  postMessage: (message: { type: string; data?: any }, panelId?: string) => void;
  sendAndSaveMessage: (message: { type: string; data: any }, panelId?: string) => void;
  handleLoginRequired: () => void;
  getConversation: (panelId?: string) => Array<{ timestamp: string; messageType: string; data: any }>;
  getState: () => StreamState;
  updateState: (updates: Partial<StreamState>) => void;
  readFile: (filePath: string) => Promise<string | undefined>;
}

export class StreamProcessor {
  constructor(callbacks: StreamProcessorCallbacks);
  processStdout(data: string): { controlRequests: any[]; controlResponses: any[] };
  processStderr(data: string): void;
  handleClose(code: number | null, intentionalKill: boolean): void;
  handleError(error: Error, intentionalKill: boolean): void;
  processJson(jsonData: any, panelId?: string): Promise<void>;
  resetBuffers(): void;
  getErrorOutput(): string;
}
```

### Changed: `src/extension.ts`

**Process Handlers Updated:**
- `_handleProcessStdout()` - Now delegates to `this._streamProcessor.processStdout()`
- `_handleProcessStderr()` - Now delegates to `this._streamProcessor.processStderr()`
- `_handleProcessClose()` - Now delegates to `this._streamProcessor.handleClose()`
- `_handleProcessError()` - Now delegates to `this._streamProcessor.handleError()`
- `_handlePanelProcessMessage()` - Now uses `this._streamProcessor.processJson()`

**Removed:**
- `_processJsonStreamData()` method (~328 lines)
- `_processRawOutput` field
- `_processErrorOutput` field

### Changed: `src/services/index.ts`

Added StreamProcessor export:
