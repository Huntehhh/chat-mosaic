## Fixed

### Process Not Killed on Session Switch
- **Problem**: Switching from internal chat to CLI session reused the old process
- **Root Cause**: `loadConversation()` didn't detect session changes; `_loadCLIConversation()` never set `_currentSessionId`
- **Fix**: Added session change detection in `loadConversation()` that kills old process; Added `_currentSessionId` assignment in `_loadCLIConversation()`
- **Files**: `src/extension.ts` lines 2849-2882, 2972-2976

### Heartbeat False Positives Killing Idle Processes
- **Problem**: ProcessManager heartbeat killed processes after 30 seconds of inactivity
- **Root Cause**: Default heartbeat config designed for long-running tasks, not interactive CLI
- **Fix**: Disabled heartbeat by setting interval to `2147483647` (max 32-bit int, ~24.8 days)
- **File**: `src/extension.ts` lines 242-244

### setTimeout Overflow Warning
- **Problem**: `Number.MAX_SAFE_INTEGER` caused "does not fit into 32-bit signed integer" warning
- **Root Cause**: JavaScript setTimeout uses 32-bit integers internally
- **Fix**: Changed to `2147483647` (max safe value for setTimeout)
- **File**: `src/extension.ts` lines 242-244

### CLI Conversations Rescanned Every History Open
- **Problem**: Opening history triggered full filesystem scan of 1800+ files every time
- **Root Cause**: No caching in `_sendConversationList()`
- **Fix**: Added 5-minute cache for CLI conversations (`_cliConversationsCache`, `_cliCacheTimestamp`)
- **File**: `src/extension.ts` lines 203-211, 3338-3352

// ProcessManager initialization with disabled heartbeat
this._processManager = new ProcessManager({
  onStdout: (data) => this._handleProcessStdout(data),
  onStderr: (data) => this._handleProcessStderr(data),
  onClose: (code, errorOutput) => this._handleProcessClose(code, errorOutput),
  onError: (error) => this._handleProcessError(error)
}, {
  intervalMs: 2147483647,  // ~24.8 days - effectively disabled
  timeoutMs: 2147483647
});

// Session change detection in loadConversation()
const previousSessionId = this._currentSessionId;
// ... load conversation ...
if (previousSessionId && previousSessionId !== this._currentSessionId) {
  if (this._processManager.isRunning()) {
    await this._processManager.kill();
  }
}

// CLI conversation caching
if (this._cliConversationsCache.length > 0 && cacheAge < this._cliCacheMaxAgeMs) {
  cliConversations = this._cliConversationsCache;  // Use cache
} else {
  cliConversations = await this._scanCLIConversations();  // Rescan
  this._cliConversationsCache = cliConversations;
}
